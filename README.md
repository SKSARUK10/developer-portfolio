## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/SKSARUK10/developer-portfolio.git
cd developer-portfolio
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Type Check

```bash
npm run typecheck
```

### Lint

```bash
npm run lint
```

## Project Structure

```
src/
├── components/         # UI components (Hero, Navbar, Projects, Contact, etc.)
├── data/
│   └── portfolio.ts    # All portfolio content — edit here to update the site
├── hooks/              # Custom React hooks
├── lib/
│   └── animations.ts   # Framer Motion animation variants
├── App.tsx
├── main.tsx
└── index.css
public/
└── assets/             # Images and static files
```

---

## Customization

All portfolio content (name, experience, projects, skills, links) is centralized in:

```
src/data/portfolio.ts
```

Edit that file to update any section of the site without touching component code.
